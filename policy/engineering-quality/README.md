# Engineering Quality — профиль Repo Factory

Версия: `engineering-quality-v1`.

Фабрика устанавливает в новые Project Manager проекты только безопасный
локальный исполнитель, стандарт и пустую конфигурацию. Менеджер обязан
заполнить конфигурацию реальными безопасными тестами своей предметной области.
Пустой список не считается успешной приёмкой.

Переустановка в уже существующий проект:
`python scripts/install_engineering_quality.py --target D:\\Dev\\project --project lvlaksim1/project`.

Безопасность: если целевой файл существует с другим содержимым, установка
прекращается без модификаций. Отчёты не попадают в Git. Отдельный MCP, сторонний
API, CI, автоматический релиз и изменение установленного ПО не требуются.

Изменения не заменяют идентичность и процедуры Context Capsule.

## Architecture Explorer — первый уровень

Общий инструмент `scripts/architecture_explorer.py --check` извлекает ссылки ProjectReference из .NET csproj, проверяет отсутствующие ссылки/циклы и строит локальные `quality/reports/architecture.json` и интерактивный `architecture.html`. Это карта проектов, **не** Roslyn-анализ классов и методов. Расширение до Roslyn допускается как отдельный последующий этап после проверки достоверности на имеющихся проектах.
